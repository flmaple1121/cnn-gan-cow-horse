# Report and presentation

`report.pdf` and `slides.pdf` are public copies of the final project documents. Their sources and required generated figures/tables are included. Student numbers have been removed. The report's sampling description is clarified: inverse-class-frequency sampling balances classes after augmentation, while the cow:horse loss emphasis of 1:5 comes from cross-entropy. Recorded metrics and model settings are unchanged.

`speaking_notes.md` and `presentation_qa.md` preserve the accompanying presentation material. `scripts/build_report_assets.py` regenerates report assets from the committed result tables and images. The two standalone Task 3 slide images are already included under `generated/figures/`.

The report uses the IEEEtran class/style and standard LaTeX packages. The included IEEEtran BibTeX style and its README retain the original third-party notices.
