# Course-provided cow-horse images

This directory contains the original 164 input PNGs: 41 cows and 41 horses in each of the Train and Test splits. `Test/Shape1` means cow (0), and `Test/Shape2` means horse (1). Training images show one animal instance per class; test images show different instances on the shared viewpoint grid.

`manifest.csv` records each relative path, label, and SHA-256 checksum. Image bytes have not been modified for publication.

Source: the Université Paris-Saclay machine vision course dataset supplied for this project. An upstream creator and a separate dataset license are not documented in the supplied files. No new data license is granted by this repository.
