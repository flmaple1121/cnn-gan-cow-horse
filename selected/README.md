# Final manual GAN selection

The final augmentation uses exactly 12 synthetic horses and no synthetic cows. The PNGs are copied byte-for-byte from the submitted project selection. `selection.csv` provides labels, repository-relative paths, and SHA-256 checksums.

The main notebook discovers this directory automatically. These images can be reused without rerunning GAN generation; Task 1 and the helper definitions must still be executed before the manual-selection/retraining cell.
